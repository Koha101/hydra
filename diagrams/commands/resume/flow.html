resume ⏯️ — Flow Through Layers

Reconnect to dead Claude session via --resume. Full transcript restored. Falls back to reportError on failure.

    U->>GW: "resume" in dead thread
    GW->>R: InboundMessage (isThread=true)
    R->>CMD: handleResumeIntercept(msg)
    CMD->>GW: react(⏯️)

    Note over CMD,SR: Look up dead session
    CMD->>SR: getByThread(existingThreadId)
    SR-->>CMD: dead SessionInfo

    alt no session found
        CMD->>GW: reportError("no session in this thread")
    else session alive (tmux running)
        CMD->>GW: "Session is already running."
    else session dead, no claudeSessionId
        CMD->>GW: reportError("no Claude session ID — use respawn")
    else session dead, has claudeSessionId
        Note over CMD,CC: Tier 1: tryResume (--resume)

        CMD->>LC: tryResume(dead)
        LC->>LC: doSpawnSession(topic, opts:
{existingThreadId, resumeFrom})
        LC->>LC: spawn tmux with
claude --resume claudeSessionId
--channels plugin:discord@...
        Note over LC: NO prompt arg
(--resume reopens existing conversation)
        LC->>SR: register new session → same threadId

        rect rgb(255, 251, 235)
            Note over LC,CC: Health check (30s)
            LC->>BT: waitForBridge(sessionId, 30s)
            CC->>BT: bridge registers
            BT-->>LC: transport.has(sessionId) = true
            Note over LC: Health check passed
        end

        LC-->>CMD: SpawnResult (success)
        CMD->>SR: removeDead(threadId)
        CMD->>GW: send(threadId, "⏯️ Resumed — full context restored.")
        CMD->>BT: notify main: "⏯️ resumed in thread"
        CMD->>CMD: debouncedRefreshListDisplay()

        alt tryResume returned null (health check failed)
            Note over CMD,CC: Tier 2: fork from dead session
            CMD->>LC: doSpawnSession(topic, opts:
{existingThreadId, forkFrom})
            LC->>LC: claude --resume sessionId --fork-session
            LC-->>CMD: SpawnResult
            CMD->>GW: "⏯️ Resumed (forked — transcript preserved)."

            alt fork also failed
                Note over CMD,CC: Tier 3: tryRespawn (fallback)
                CMD->>LC: tryRespawn(threadId, topic)
                LC->>LC: doSpawnSession(topic, opts:
{existingThreadId, resurrectFrom})
                Note over LC: Fresh session reads thread
via fetch_messages
                LC-->>CMD: SpawnResult
                CMD->>GW: "🔁 Respawned (resume unavailable)."

                alt respawn also failed
                    CMD->>GW: reportError("all recovery methods failed")
                end
            end
        end
    end
